# HexSoftwares Resume Website

A professional resume website built using pure HTML as part of the HexSoftwares Frontend Development Internship.

---

## Live Demo

🔗 https://fazal305.github.io/HexSoftwares_Resume_Website/

---

## Project Overview

This project was created to demonstrate a clean and professional online resume using only HTML. The website presents personal information, technical skills, soft skills, and contact details in a simple and accessible format.

The project follows the HexSoftwares internship requirement of using only HTML with no external frameworks, libraries, or JavaScript.

---

## Features

- Professional header section
- Profile photograph
- About Me section
- Technical skills list
- Soft skills list
- Contact information
- Semantic HTML structure
- Single-page resume layout
- Responsive and readable design
- Built using a single HTML file

---

## Technologies Used

- HTML5
- Internal Style Block
